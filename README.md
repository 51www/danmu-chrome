# Danmu Overlay

在配置清单匹配的视频页面上，叠加自建 `danmu_api` 弹幕的 Chrome 扩展（Manifest V3）。

## 功能

- 配置清单驱动：按网址规则自动注入，新增站点无需改代码
- 自动装填：命中规则后抓取视频标题，自动搜索作品、按集数选剧集并加载弹幕
- 手动搜索：自动匹配不准时，可在弹窗中搜索作品、选择剧集
- 弹幕叠加：跟随视频时间、支持暂停/拖动/全屏，不拦截播放器操作
- 可配置：API 地址（含鉴权参数）、站点规则、弹幕样式均可在配置页修改

## 安装

1. 打开 Chrome 的 `chrome://extensions`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录 `/Users/apple/Documents/www/danmu-chrome`

## 首次使用

1. 点击插件图标 → 打开「配置」
2. 直接点击「保存更改」一次，用于授予示例站点的主机权限
3. `https://tv.lxyy.club/` 规则已默认添加，打开该站影片播放页即可自动装填弹幕
4. 如未命中或匹配不准，在弹窗中手动搜索
5. 想把当前网站加入清单：在该网站打开插件弹窗，点「+ 当前网站」，配置页会自动带入 `*://域名/*` 规则，点「添加并保存」后直接生效

## 配置说明

配置页按区域维护：上方填写弹幕服务，中间用表格增删改查站点规则，下方设置弹幕样式。新增、编辑、删除规则会直接保存；服务地址和样式改动需点底部「保存更改」。

主要字段：

| 字段 | 说明 |
| --- | --- |
| `apiBase` | 弹幕 API 完整地址，可含任意鉴权参数，默认 `https://danmu-api-93060.app.workbuddy.host?sharecode=4ZIBWTWGZ4` |
| `rules` | 站点规则清单，表格每行一条，含名称、网址模式、标题选择器、自动填充/装填开关 |
| `style` | 弹幕字号、颜色、透明度、速度、最大行数 |
| `cacheTTL` | API 结果缓存毫秒数 |

新增或编辑规则时在弹窗中填写：网址模式每行一条，标题选择器按优先级每行一条。底层配置结构与示例见 `docs/需求文档.md` 第 7 节。

## 弹幕服务

默认对接：

- API 地址：`https://danmu-api-93060.app.workbuddy.host?sharecode=4ZIBWTWGZ4`
- 接口：`/api/v2/search/anime`、`/api/v2/search/episodes`、`/api/v2/comment/:id`

如更换服务或鉴权参数，在配置页修改 API 地址后保存即可。不同服务的参数名（如 `token`、`key`、`sharecode`）都可直接写在地址里。

## 注意事项

- `tv.lxyy.club` 的播放器在跨域 iframe 中。首次加载弹幕时 Chrome 会提示允许访问所有站点，需同意后插件才能把弹幕注入播放器 iframe。
- 标题抓取不准时，在配置页调整对应规则的 `titleSelectors` 即可。
- 弹幕服务默认有请求限流，插件已做 GET 缓存，不建议频繁手动刷新。
- 当前服务未提供公开发送弹幕接口，因此插件只读展示弹幕。

## 文件结构

- `manifest.json`：扩展声明与权限
- `background.js`：API 代理、缓存、规则注册、自动装填
- `content.js`：视频识别与弹幕渲染
- `popup.html` / `popup.js`：弹窗界面与手动搜索
- `options.html` / `options.js`：配置页
- `icon.png`：扩展图标
- `docs/需求文档.md`：需求与验收标准
